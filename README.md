# Amy's Hebrew Journey

Een simpele statische website voor een Hebreeuwse vlog.

## Openen
Dubbelklik op `index.html` om de site in je browser te openen.

## Aanpassen
- Tekst en videokaarten: `index.html`
- Kleuren en vormgeving: `styles.css`
- Interactie: `script.js`

## Later uitbreiden
Je kunt echte YouTube/TikTok/Instagram embeds toevoegen, een contactpagina maken,
of deze site publiceren via GitHub Pages, Netlify of Vercel.
